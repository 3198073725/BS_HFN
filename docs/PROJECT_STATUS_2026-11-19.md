# BS_HFN 项目总结与更新记录

更新时间：2026-11-19。本项目用于本地毕业答辩，当前可从 Windows 启动 Flask、Celery、Vue 三个任务。技术栈为 Vue 3、Element Plus、Vite、Pinia、Axios、HLS.js、ECharts、Flask、SQLAlchemy、MySQL、Redis、Celery、FFmpeg。AI 扩展使用本地 faster-whisper 与 DeepSeek。

交付核对日期：2026-11-20。本次功能快照与另一台电脑更新脚本一并交付。

## 本次改动的最终口径

1. “AI 总结”位于课程详情的“视频笔记 / 我的提问”同一标签栏，内容区全宽显示并适配手机。
2. 每次点击生成只提交当前 video_id，字幕和总结分别按该视频独立保存；切换视频读取各自记录。后台不遍历整门课程，不将课程级旧总结冒充为各视频总结。
3. FFmpeg 提取单声道 16kHz WAV，本地 Whisper 识别带时间轴文本，再使用 DeepSeek 生成总结。FFmpeg 本身不负责语音识别。已有且源指纹未变的字幕可复用，临时音频正常结束后清理。
4. 流程为 QUEUED → EXTRACTING → SUBTITLING → SUMMARIZING → DRAFT → PUBLISHED。教师可编辑、保存草稿、审核发布。FAILED 可重试，CANCELLED 代表取消。进度显示阶段和已识别时间，并非准确剩余时间。
5. 取消检查在提取音频轮询、字幕段返回、AI 请求前后执行。模型计算或网络请求正在执行时，要等检查点才能退出；已取消或任务身份不匹配的旧任务不能覆盖结果。
6. 普通课程的学生需选课并完成当前视频，才能看该视频已发布且未失效的总结。“C语言学习”允许所有正常登录学生查看已发布的视频总结；未审核草稿和下线课程仍受权限保护。
7. 学生阅读端按 Markdown 展示标题、列表、加粗、引用、代码块和表格；原始 HTML 不执行，危险协议链接不可点击。教师继续编辑 Markdown 原文。
8. DeepSeek 密钥只存 backend/.env，浏览器和公共仓库不保存密钥。模型放在 tools/whisper-small，实际 .env 可用相对路径 ../tools/whisper-small。
9. E:\BS_HFN 在当前电脑是指向 F:\Codex\Projects\BS_HFN 的 Junction。Vite 已统一真实根目录与 cwd，支持从两种路径启动。

## 数据库

当前为 **29 张业务表**，另有 alembic_version，最新迁移为 `30cc40dd50ee`。

| 新表/迁移 | 用途 |
| --- | --- |
| video_subtitle / 10aa20bb30cc | 视频唯一关联；字幕时间段 JSON、语言、源文件指纹 |
| course_ai_summary / 10aa20bb30cc | 保留历史课程级总结和课程开放策略，旧批量生成入口已停用 |
| course_ai_summary.open_to_students / 20bb30cc40dd | 按课程控制已发布视频总结是否向全部学生开放 |
| video_ai_summary / 30cc40dd50ee | 视频唯一关联；正文、生成状态、任务 ID、资料指纹、错误、阶段进度 |

删除视频会级联删除字幕和视频总结；课程删除会清理其关联数据。升级使用增量迁移，不重建业务表。代码同步不会复制本机 MySQL 中已生成的字幕、总结、发布状态或演示记录。

## 验证与使用边界

- 按视频改造后的后端回归：103 项通过、5 项跳过；跳过项为需额外开关的集成检查，不代表它们已执行。
- 本次交付全量回归：109 项通过、5 项跳过，包含更新脚本的 6 项保护测试；ANSI 部署检测在本机为 24 项通过、3 项按快速模式跳过、0 项失败。
- 已验证数据库迁移与 ORM 模型一致，历史表行数与进度迁移回归通过。
- 前端生产构建通过，浏览器模拟接口验证只生成所选视频、切换视频不串总结。
- Markdown 解析和浏览器学生端验证通过，覆盖标题、列表、表格、代码块、危险链接及手机宽度。
- 本地 small 模型真实加载成功，真实视频前 15 秒识别成功。CPU 识别长视频仍会耗时，不能承诺实时字幕。
- 实际生成依赖本机 API Key、DeepSeek 余额和网络、Redis、Celery、FFmpeg、模型；构建通过不代表另一台电脑已完成真实 AI 联调。
- 现有视频不会因为更新代码就全部生成字幕，教师需要逐个视频发起。已发布结果保存在数据库，未调用自动播种或付费批量生成。

下一步建议以一段短视频在更新电脑上完成“生成字幕 → 总结草稿 → 教师发布 → 学生查看 → Markdown 阅读”验收，再处理长视频。公网部署、GPU 加速、课程级汇总和字幕校对编辑可作为后续扩展，不应在论文中写成已经完成。
