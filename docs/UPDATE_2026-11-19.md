# 另一台 Windows 电脑更新本次改动

适用于另一台电脑已经部署并有自己的数据库、backend/.env、便携 FFmpeg 的情况。只更新代码和数据库结构，不导入本电脑的业务数据。首次部署仍按 [完整迁移手册](WINDOWS_MIGRATION_SETUP.md) 操作。

## 运行前

先关闭另一台电脑的 Flask、Celery、Vue/Vite 三个终端，确保没有正在上传、转码、识别或批改的操作。MySQL 和 Redis 保持运行。不要在本电脑运行脚本来代替更新另一台电脑。

进入那台电脑实际的项目根目录，例如 E:\BS_HFN。第一次取得新脚本时执行：

```powershell
cd E:\BS_HFN
git status
git pull --ff-only origin main
```

如果 git status 显示源码或未跟踪文件，请先备份并处理，不要执行 reset --hard 或 clean。如果拉取失败提示鉴权，配置那台电脑的 GitHub SSH Key；也可自行将 origin 改为该仓库的 HTTPS 地址后使用 Git 凭据管理器。不要把 GitHub 密码或 Token 写入脚本。

首次拉取仅为了获得脚本，先不要启动应用；新代码需要完成下面的依赖和数据库更新。

## 使用脚本

根目录 `update-project.bat` 使用纯 ASCII 内容（兼容 Windows ANSI），双击即可执行；它调用 UTF-8 的 Python 更新程序，整个流程与电脑盘符无关。

只检查条件：

```powershell
.\update-project.bat --check
```

正式更新：

```powershell
.\update-project.bat
```

已经手动复制模型，或使用自定义 WHISPER_MODEL 且不希望脚本下载模型时：

```powershell
.\update-project.bat --skip-model-download
```

此选项只跳过下载，并不保证自定义模型可用。没有模型仍然可以使用其他功能，但不能生成字幕。默认会检测 .env 所指本地模型；缺失的标准 small 模型会下载到 tools/whisper-small。模型约 460 MiB，建议通过 U 盘复制本电脑的整个 tools/whisper-small 目录以减少下载等待。不要复制 .venv 或 node_modules。

## 脚本执行内容

1. 检查 main 分支、origin 仓库、Git 工作区、Python、npm 实际运行、mysqldump、.env、FFmpeg，以及 Flask/Vite/Celery 是否已停止。发现本地源码改动或运行中的服务就退出。
2. fetch 远程 main，确认只能快进更新，不做强制覆盖。
3. 使用 mysqldump 备份那台电脑的数据库，复制其 .env 并记录原提交、原业务表行数、学习累计值。备份失败就停止。
4. git pull --ff-only，再安装 backend/requirements-ai.txt，包含兼容版本的 faster-whisper、PyAV。
5. 仅补充 .env 中不存在的 AI 配置键，保留已有数据库连接、JWT 密钥、DeepSeek Key、自定义模型等设置。密钥不会输出到终端。
6. 检测或下载模型；运行 Flask 数据库增量迁移；校验原有表行数、学习累计值和 ORM 模型。
7. 按唯一课程名称“C语言学习”恢复向所有学生开放总结的规则，不假设课程 ID 为 4，不自动生成或发布内容。找不到唯一匹配时提示跳过，不改其他课程。
8. npm ci、npm run build、pip check、Markdown 检查；完成后提示手动启动应用。

SQL 位于 backend/backups，配置和版本快照在 backend/backups/update-日期时间。快照可能包含密钥，不要上传。脚本不会自动恢复数据库，避免失败时用旧备份覆盖新数据。

## 配置并重新启动

在另一台电脑的 backend/.env 填入本机需要的配置：

```dotenv
DEEPSEEK_API_KEY=填写自己的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
WHISPER_MODEL=../tools/whisper-small
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
```

已有有效值不用重填。随后双击 start-dev.bat，重启后的 Celery 必须包含 video.generate_summary 任务。浏览器使用 Ctrl+F5 强制刷新，旧页面调用课程批量接口会得到 410。

## 验收

- 打开“C语言学习”，切换不同视频，AI 总结应显示当前视频名称。
- 用短视频生成，任务只处理当前视频，显示阶段和进度。
- 教师保存草稿并发布，学生读取格式化的 Markdown。
- 验证取消和重试；已完成字幕会缓存复用。
- 查看已存在的课程、学生、学习进度、作业附件和视频，确认它们仍然存在。
- 可执行 `check-deployment.bat --quick --no-pause` 检查环境；当前应为 29 张业务表、迁移 30cc40dd50ee。

## 哪些内容 Git 不会同步

backend/.env、DeepSeek 密钥、tools/ffmpeg、tools/whisper-small、backend/media、数据库和备份均不进入仓库。

因此另一台电脑能得到最新功能，但不会自动得到本电脑新生成的字幕、AI 总结及其发布状态。它可以使用自己的视频重新生成。如果需要两台电脑的数据也完全一致，应另做“数据库备份恢复 + 媒体复制”，恢复会涉及覆盖那台电脑已有业务数据，不能把代码更新脚本当作数据同步脚本。
