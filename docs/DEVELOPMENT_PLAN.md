# 开发计划

本计划以 `BS_HFN.md` 和 `BS_HFN数据库文档.md` 为唯一产品与数据设计基线。

## 阶段 0：工程基线（已完成）

- [x] 清理旧项目代码和本地依赖
- [x] 建立 Flask Application Factory 与 Blueprint 边界
- [x] 建立 18 张业务表 ORM 模型
- [x] 建立 Vue 3 + Vite 前端骨架
- [x] 建立 FFmpeg、ffprobe、Celery 代码入口
- [x] 增加环境变量模板、忽略规则和基础测试
- [x] 初始化 Git 仓库（`main` 分支）
- [x] 配置 Git 用户身份并提交基线
- [x] 安装依赖，生成首次 Flask-Migrate 迁移

## 阶段 1：认证与权限

- [x] 用户注册、登录、刷新 Token、退出
- [x] 学生/教师/管理员角色装饰器
- [x] 用户禁用与登录状态校验
- [x] 管理员和课程分类种子数据
- [x] 前端登录、会话恢复和路由保护

验收：三种角色均可登录，越权请求返回 403。

## 阶段 2：课程垂直链路

- [x] 课程分类查询
- [x] 教师创建、编辑、发布和下线课程
- [x] 教师创建和排序章节
- [x] 学生浏览已发布课程
- [x] 教师资源所有权校验

验收：教师能够创建“课程 → 章节”，学生只能看到已发布内容。

## 阶段 3：同步视频链路

- [x] 安装并验证 FFmpeg/ffprobe
- [x] 上传文件校验、UUID 命名与落盘
- [x] ffprobe 元信息提取
- [x] MP4 转码、HLS 切片与封面生成
- [x] 视频状态查询接口
- [x] hls.js 播放器接入

验收：上传一个 MP4 后可以在课程章节中播放 HLS。

## 阶段 4：Celery 异步化

- [x] Redis broker 配置
- [x] `process_video(video_id)` 实现
- [x] 数据库提交成功后再投递任务
- [x] PENDING/PROCESSING/READY/FAILED 状态流转
- [x] 失败信息、指数退避重试和残留文件清理

## 阶段 5：学习与答疑

- [x] 加入课程、收藏
- [x] 学习进度与断点续播
- [x] 视频时间点笔记
- [x] 学生提问与教师回答

验收：学生加入课程后可恢复视频进度、记录时间点笔记并提问；课程教师可查看、回答和关闭问题，其他用户不能越权访问。

## 阶段 6：作业、测验、统计与后台

- [x] 作业发布、附件、提交、重复提交和批改
- [x] 单选/判断试题、限时答题和自动评分
- [x] 公告草稿、发布、下线和首页展示
- [x] 学生/教师/管理员实时聚合统计和管理员页面

验收：作业与测验均完成教师发布、学生参与、结果回看和越权保护；管理员可管理账号与公告；统计数据直接从业务记录实时聚合，不建立冗余统计表。

## 阶段 7：稳定性与数据生命周期（已完成）

- [x] 统一应用写入时间为 UTC，并在 API 时间字段中显式返回 `Z`
- [x] 固定 MySQL 连接会话时区，避免服务器本地时区造成时间偏移
- [x] 收紧课程、作业与测验状态流转，拒绝重复或逆向操作
- [x] 补齐 SQLAlchemy 级联关系，使其与数据库外键删除策略一致
- [x] 删除课程或作业草稿时同步清理受控目录内附件
- [x] 支持删除误建的作业、测验草稿，并保留所有权和状态校验
- [x] 学习进度累加与测验提交增加并发保护

验收：关键生命周期操作有接口测试覆盖；MySQL 模型无迁移漂移；前端生产构建通过。

## 阶段 8：浏览器端到端验收（已完成）

- [x] 引入 Playwright 与 Chromium 测试环境
- [x] 使用内存 SQLite 和专用账号隔离端到端测试数据
- [x] 覆盖登录提示、登录后原路径恢复和角色路由保护
- [x] 覆盖学生、教师、管理员核心页面导航
- [x] 覆盖 390 px 移动端登录与横向溢出检查
- [x] 覆盖教师创建课程、添加章节、发布与学生浏览加入的跨角色流程
- [x] 覆盖作业、测验的跨角色写入闭环
- [x] 覆盖网络失败中文提示和真实 HLS 视频播放
- [x] 覆盖长文本安全断行、空数据、慢请求加载反馈和移动端学生业务页面

验收：Chromium 端到端测试 13/13 通过；真实 HLS 测试媒体由项目内 FFmpeg 自动生成，测试数据使用内存 SQLite，不污染开发数据库。

3. 补充教师与管理员密集表格在手机上的专项交互优化和视觉快照。
