## 视频处理样例

| 条目 | 初始状态 | 预期操作 |
| --- | --- | --- |
| 可恢复的转码失败 | 失败，源文件有效 | 重新转码后生成标准MP4/HLS/封面，最终可播放 |
| 等待超时任务 | 等待超过30分钟 | 点击重新转码人工恢复 |
| 处理中断任务 | HLS阶段超过30分钟未更新 | 点击重新转码人工恢复 |
| 损坏原始文件 | 失败，文件存在但不是有效视频 | 重试仍会失败，可展示原因并清理 |
| 原始文件丢失 | 失败，文件不存在 | 不允许恢复，仅清理失败条目 |

这些异常条目位于“数据结构与算法（备课草稿）”的运维样例章节，明确是演示夹具，预置时没有投递真正的后台任务。要展示真实上传，可以在教师端选择本机 `backend/media/defense_assets/c/source.mp4`，上传到一个草稿课程并查看处理阶段。

## 时间与重复演示

一般开放作业和测验的截止时间设置到准备日期后一年，避免答辩前自动失效；未来测验为准备日期后一周开始，历史任务已截止。1分钟测验从学生实际点击开始时计时，不会因准备数据后过了几天而无法启动。

预置的待审批密码请求有效期为24小时；已有的续答记录会按30或60分钟限时过期。若答辩不是今天，现场重新发起密码申请，续答则用李晨尚未参加的“阶段能力测验”现场开始。不要依赖几天前的待审批/续答时间状态。

同一学生同一测验只能正式提交一次，已通过申请、已评分作业和视频清理也会改变数据。重复运行初始化命令不会回滚这些操作。第二次演示可换其他学生，或由教师新建测验/作业；不要为了重置演示而删除原有数据库。

## 文件与维护命令

数据已建立，以下命令用于验证或搬迁，不必在每次启动时执行。

```powershell
cd E:\BS_HFN\backend
```

`seed_demo --check` 与浏览器演示冒烟脚本检查初始场景基线；审批、删除视频或重置密码后，基线状态会变化，应结合实际操作判断。接口验证会登录/退出新建演示账号，不审批、不交卷、不清理视频。

初始化命令为 `python -m scripts.seed_demo`：只允许开发环境、先用mysqldump完成SQL备份、再单事务新增；检测到已完成标记即直接返回，不重复新增或重置状态。失败时回滚数据库，并清理本次创建的文件，保留原有媒体。没有提供全库删除或自动恢复命令。
