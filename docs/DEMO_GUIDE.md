## 时间与重复演示

一般开放作业和测验的截止时间设置到准备日期后一年，避免答辩前自动失效；未来测验为准备日期后一周开始，历史任务已截止。1分钟测验从学生实际点击开始时计时，不会因准备数据后过了几天而无法启动。

预置的待审批密码请求有效期为24小时；已有的续答记录会按30或60分钟限时过期。若答辩不是今天，现场重新发起密码申请，续答则用李晨尚未参加的“阶段能力测验”现场开始。不要依赖几天前的待审批/续答时间状态。

同一学生同一测验只能正式提交一次，已通过申请、已评分作业和视频清理也会改变数据。重复运行初始化命令不会回滚这些操作。第二次演示可换其他学生，或由教师新建测验/作业；不要为了重置演示而删除原有数据库。

## 附件试卷演示

教师在“测验管理 → 创建测验”选择“附件试卷（教师批改）”，选择已发布课程、填写名称并上传试卷，点击“保存并发布”后确认即可，不需要添加系统题目。学生开始该测验后查看试卷，填写文字或上传答卷；草稿自动保存，正式交卷后不可修改。教师从课程测验卡片的“答卷与批改”进入，预览答卷并保存评分与评语；学生随后可查看结果。在线试题测验继续沿用自动评分流程。

3. 管理员视频表格：展开“查看完整信息”阅读长文件名和课程位置，展开“查看错误原因”阅读全文，均可Tab聚焦、Enter切换。展开详情仅内部滚动，不无限撑高。手机表格不再固定左右列，左右滑动查看全部列；桌面固定列保留。

本阶段无新数据库迁移。异常场景回归在隔离环境进行，真实答辩数据勿反复替换、交卷或审批来演练；更新后重启后端、刷新旧页面即可。

## 阶段33：答疑与学习交互

- 教师筛选“等待回答”，回答或关闭后记录从该筛选列表移除，末页删完会回退。学生先关闭问题后，教师迟到的回答/修改会被拒绝，不会重新打开问题；教师遇到409会读取最新详情，已关闭则关闭回答弹窗。
- “我的学习”用Tab进入当前标签，左右方向键切换已加入/我的收藏，Home/End直达首尾；标签与面板有明确关联。取消收藏或退出请求中禁止重复点击；取消确认或点叉只关闭，不误报失败。
- 答疑及通知支持连续英文长文本换行，正文换行保留。异常回归使用隔离数据；本轮没有新增迁移或重置真实演示记录。

## 阶段34：弹窗与长名称展示

- 用键盘打开弹窗，关闭后回到原入口；附件预览嵌套在批改/测验中时先回到预览按钮，外层关闭再回到列表。答疑处理后原筛选项移除，则回到页面标题。
- 消息中心的未读通知移除后，键盘焦点回到邻近通知；列表为空回到“只看未读”开关。开关可用空格切换，慢请求中移到导航栏不会被强制拉回。
- 课程/班级/分类管理、审计与批改记录中被截断的字段出现“全文”，Tab聚焦后Enter展开；全文保留换行、内部滚动，短名称或宽屏完整显示时不出现多余入口。
- 教师公开主页每页显示6门已发布课程，底部切换更多课程；课程总数仍是完整数量。空数据和单条不会显示分页。课程中心筛选数据减少不会停在旧空末页。
- 本轮仅前端调整，正常刷新页面即可，无需重新初始化演示数据或运行新迁移。

## 阶段35：章节与视频统一编辑

- 教学管理展开课程后，点击章节的“编辑”，同一个弹窗中维护章节标题/说明/排序和本章节的视频。外部“上传视频”是进入该弹窗上传区的快捷入口。
- 视频列表里的“编辑视频”“替换文件”只在当前弹窗内展开表单，不打开另一个视频弹窗；保存视频成功仍留在章节管理，未保存章节资料不会被刷新覆盖。章节资料与视频分别保存，关闭并不替代保存。
- 添加新章节后先“保存章节”，生成编号后上传按钮启用，继续在同一个弹窗上传本章节的视频。已发布课程不能替换/删除已有视频，需先下线；资料编辑不会清除学生学习记录。
- 本次无需新迁移，刷新前端即可。替换/删除会清除原视频学习记录，仅在隔离测试或专门准备的演练记录中操作，不要为了看界面随意替换真实答辩视频。

## 阶段36：课程缩略图与ECharts

- “我的学习”的已加入和收藏卡片都使用横向16:10缩略框，完整等比显示图片；极宽/竖向图片会留白，不裁掉文字。无封面或加载失败显示课程首字，卡片仍保持相同尺寸。
- 学生进入“数据概览 / 学习数据”，查看“学习与成绩概览”和“累计学习与任务记录”，展开“查看图表数据”核对卡片数值。前者是进度/得分率，不是作业提交率；后者各项记录计数不能相加。
- 教师进入“数据概览 / 教学数据”，查看课程进度与得分率对比和发布状态；超过6门课程用图表底部分页切换，展开数值表查看被截断的课程名称。课程状态图统计全部课程，不随对比图分页改变。
- 管理员在后台指标下展开“查看数据图表”，展示角色及视频状态分布；保持中性色，默认折叠，不干扰视频处理工作区。图表用全部统计接口结果，不随列表搜索改变；统计不是自动后台实时流，教师/学生可“刷新数据”，管理员随后台总览读取更新。
- 未评分的均分0遵循接口口径，不等于有零分答卷。全零数据展示明确空状态，没有伪造趋势。图表与折叠数据表都可随窗口尺寸变化，教师/管理员仍推荐桌面演示。
- 新增ECharts npm依赖，本机已经安装；换机器时先在frontend执行 `npm ci`。无需数据库迁移或重新导入演示数据，现有前端刷新即可。本轮数据库文档更新是补录已有的进度去重表，并非新增数据库操作。
- 论文实现章节与ER图请按 `THESIS_IMPLEMENTATION.md` 及数据库设计第63～65节同步；项目内没有原始论文正文，说明文件不是对外部Word论文的自动修改。

## 阶段37：班级任务、不限时作业与测验模式

1. 学生先加入已关联教学班的课程，再申请班级但暂不让教师审批。此时“作业管理”和“在线测验”不能出现该班级任务，直接访问任务编号也会被拒绝；学生不会收到这两类任务的发布通知。教师在“班级管理 → 入班审批”同意后刷新，已有班级作业与测验立即可见。
2. 教师创建作业时默认选择“不限时”，无需填写日期即可保存并发布，卡片显示“长期有效”；学生可提交，直到教师点击关闭。选择“指定截止时间”后日期成为必填项，空日期不会偷偷改为当前时间。
3. 教师创建测验时选择“在线试题”，弹窗不出现试卷上传，保存后进入试题管理，可添加单选题、判断题并由系统评分。选择“附件试卷”才出现完整试卷上传，发布后学生提交文字或附件答卷，由教师人工批改。不要把学生答卷附件与教师完整试卷混为一项。
4. 管理员进入视频处理，点击“重新转码”等需要确认的操作；取消按钮为白底灰边，确认按钮为深灰色，桌面和手机均保持紧凑居中。颜色只表达操作层级，不使用突兀的蓝、红、绿背景。

本阶段无需数据库迁移或重新导入数据。为了避免污染答辩数据，审批与交卷演练建议使用专门演示账号；完成后可保留结果作为流程展示，或重新执行演示数据脚本恢复隔离数据。
