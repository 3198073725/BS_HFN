## 已发现并修复

1. 删除无效且不安全的全局 Git `user.password` 明文配置；保留姓名和邮箱。
2. 固定测试环境为同步视频模式，避免本地 `.env` 污染测试并误连默认 AMQP。
3. Refresh Token 改为单次轮换，退出时可同时注销同一用户的 Access/Refresh Token。
4. 前端增加 Access Token 过期后的单次并发刷新与请求重放。

59. 管理后台原先只有账号和公告，且无法发现或处置视频处理故障；现新增视频处理中心，展示 FFmpeg/ffprobe 状态、队列模式、任务阶段、媒体参数、原文件状态和失败原因，允许安全恢复失败/超时任务及清理失败文件，并补齐课程上下线、班级和课程分类的跨教师监管入口。

62. 上一版为去除模板化观感将视觉压得过平，页面标题、卡片、表格和弹窗缺乏层级。现采用克制的高校门户编辑式风格：保留单一蓝灰色，使用细边框、轻阴影、标题侧标和有限悬停反馈区分内容层级；课程、学习、班级、作业、测验、答疑、统计及账号页统一圆角与表面节奏，管理员操作区仍保持灰阶，并修正手机首页标题孤字断行。
63. 班级原先只有成员名册，无法承载真实授课安排。现新增班级课程关系：教师可关联自己的草稿、已发布或已下线课程，关联时自动将现有名册加入课程，后续新增学生也会同步；学生班级页只展示已发布课程。解除关联、移出学生和删除班级均保留原有课程关系与学习记录，避免教学调整造成数据丢失。
64. 教师原先只能上传视频，无法在上传后修订资料或处理失败和过期内容。现补齐单视频资料编辑、失败重试、源文件替换和安全删除：元数据可随时修改，替换与删除仅限草稿或已下线课程且禁止操作处理中任务；替换和删除会清理对应学习进度、笔记与答疑数据，页面在执行前明确告知影响，并通过所有权、文件路径和媒体格式校验阻止越权或危险操作。
65. 班级与课程关联后仍缺少班级维度的数据反馈，教师只能看到全课程统计。现新增班级教学进展接口和详情区，以当前名册为统一分母，严格限定关联课程和班级成员，展示视频平均进度、作业提交率与批改后平均分、测验完成率与交卷后平均分，并拆分到每门课程；班级切换和名册、课程关系变更后会自动刷新，异步响应使用序号隔离避免串班。
66. 管理员用户、课程和视频接口原先会一次返回全部数据，数据增长后会拖慢页面和数据库；现统一改为带页码边界的服务端分页，视频仍保留全局处理汇总。新增只读操作审计表和后台工作区，记录管理员、动作、对象、摘要、来源与时间，覆盖账号、视频、课程、班级、分类和公告的关键变更，并明确排除密码等敏感字段。
67. 答辩版补齐五项可靠性功能：用户可使用已登记身份信息找回密码，管理员可代重置师生密码；新增站内消息及作业、测验、答疑通知；作业附件通过鉴权接口在线预览；测验答案自动保存且超时仅按截止前草稿交卷；学习进度断网后使用用户隔离的本地队列恢复补传。
68. 学生找回密码由立即生效改为教师审批：身份核验后生成 24 小时申请并通知当前班级教师，教师在班级名册上方同意或拒绝；后端按当前师生关系校验权限，管理员代重置时取消旧申请，避免越权审批和密码被延迟覆盖。
69. 自主加入课程与加入教学班原先是两套单向关系，学生加入课程后无法选择班级。阶段 22 先补齐了课程详情读取关联班级的入口和入班后的课程同步；同时增加用户主页体系，教师头像和姓名可进入仅展示公开资料与已发布课程的主页，右上角头像进入本人资料编辑，联系方式不对外公开。
70. 课程详情直接入班不符合实际教学管理流程。现改为学生提交入班申请、班级教师审批：待审批阶段不创建班级成员和课程关系，同意后才同步班级课程，拒绝后允许再次申请；教师只能处理本人班级申请，双方通过站内消息获得申请与结果通知。
71. 学生此前只能在课程弹窗查看当前申请状态，缺少集中记录和撤回入口，消息中心还会直接显示内部分类代码 `CLASS`。现于“我的班级”增加申请记录区，展示班级、教师、来源课程、状态和时间；学生只能撤回自己的待审批申请，撤回后可以重申，并将所有班级类消息统一标记为“班级通知”。
72. 课程详情顶部入班入口原先是固定“加入班级”，且仅打开弹窗时读取关系，导致已经入班仍显示未加入。现进入详情即读取真实成员及申请状态，区分“加入班级”“待教师审批”“已加入班级”；重新打开班级列表、切回页面和网络恢复时刷新，过期响应不会覆盖当前课程，审批同步选课时也更新尚未加入的课程状态，不重置已有学习会话。已加入入口仍可查看多个关联班级。
