# 当前实现审计报告

审计日期：2026-09-12

## 已发现并修复

1. 删除无效且不安全的全局 Git `user.password` 明文配置；保留姓名和邮箱。
2. 固定测试环境为同步视频模式，避免本地 `.env` 污染测试并误连默认 AMQP。
3. Refresh Token 改为单次轮换，退出时可同时注销同一用户的 Access/Refresh Token。
4. 前端增加 Access Token 过期后的单次并发刷新与请求重放。
5. 公开课程和视频接口不再暴露未完成视频及其内部错误信息。
6. Celery 投递失败现在返回 503，并持久化 `FAILED/QUEUE`，不再永久停在 `PENDING`。
7. 视频任务增加两次指数退避重试；重试等待期间回到 `PENDING`，最终失败保留错误信息。
8. FFmpeg 处理步骤统一为数据库文档定义的 `PROBING/TRANSCODING/HLS/COVER/FINISHED`。
9. 转码失败和删除章节/课程时清理派生媒体文件，且限制清理范围只能位于媒体根目录。
10. 支持中文原始视频名，拒绝空文件、超长文件名和负数排序。
11. Windows 下 FFmpeg/ffprobe 输出改为容错解码，消除中文路径导致的读取线程异常。
12. 移除未使用且存在中危 XSS 公告的 ECharts 5；统计模块开发时再引入安全版本。
13. Vite 从 5.4.21 升级到 6.4.3，消除旧版 esbuild 的开发服务器安全公告。
14. 生产环境启动时强制校验至少 32 位的 Flask/JWT 密钥，并收紧默认 CORS 来源。
15. 重做登录、注册、首页、课程、教学管理与错误页，补齐表单提示、校验、提交状态和移动端布局。
16. hls.js 改用轻量构建，并按 Vue、HTTP、HLS 拆分产物，所有 JavaScript 分块均控制在 500 kB 以下。
17. 完成课程加入/退出与收藏，重复操作通过唯一约束和事务返回明确冲突。
18. 学习进度由后端根据视频时长计算，限制时间边界和单次观看增量，达到 90% 自动完成。
19. 视频笔记和答疑增加学生成员校验、内容所有权及教师课程所有权校验。
20. 退出课程仅停用关系，不删除历史进度、笔记和问题，避免学习数据意外丢失。
21. 作业闭环补齐截止时间、课程成员、教师所有权、重复提交重置成绩和批改分值上限校验。
22. 作业附件改为白名单格式、50 MB 上限和 UUID 路径，替换时只允许清理媒体根目录内文件。
23. 测验发布前校验题目分值合计，限制作答窗口和正式提交次数，正确答案在学生交卷前不返回。
24. 公告实现草稿、发布、下线与公开展示，已发布公告必须先下线才能编辑或删除。
25. 学生、教师、管理员统计均从学习记录、作业提交和测验记录实时聚合，不增加易失真的统计表。
26. 管理后台增加用户查询、教师/学生创建和账号启停；管理员账号不允许在普通用户操作中被禁用。
27. 应用时间统一按 UTC 写入并以带 `Z` 的 ISO 8601 格式返回，MySQL 连接会话固定为 UTC，避免前后端和不同部署主机产生时区偏移。
28. 课程发布/下线改为严格状态机，重复发布、重复下线和非法逆向操作返回 409。
29. ORM 级联关系与数据库 `ON DELETE CASCADE` 对齐，修复删除草稿课程时尝试把非空外键置空的问题。
30. 删除草稿课程、作业时同步清理受控媒体目录内附件；作业和测验补齐仅限所有者删除草稿的操作入口。
31. 学习进度更新和测验正式提交增加数据库行锁及冲突处理，降低并发请求造成累计丢失或重复写入的风险。
32. 建立 Playwright 隔离测试环境，自动启动独立前后端并使用内存 SQLite，避免浏览器测试污染开发数据库。
33. 浏览器自动化发现 Element Plus 服务型确认框仍使用英文按钮，现已通过全局中文语言配置统一为中文。
34. Axios 无响应与超时异常原先缺少可读提示，现统一返回中文网络错误，并增加页面保持可用的断网测试。
35. 浏览器自动化补齐作业提交与批改、测验作答与自动评分两条跨角色写入闭环。
36. 隔离后端使用项目内 FFmpeg 自动生成三秒 HLS 测试媒体，并验证 Chromium 实际加载播放列表、切片且播放时间持续推进。
37. 移动端边界测试发现超长连续字符会在课程卡片内裁切，现已增加安全断行，并覆盖学生核心页面无横向溢出、空状态和慢请求加载反馈。

## 验证结果

- 后端测试：25/25 通过，包含真实 FFmpeg 链路，以及学习、答疑、草稿级联删除、作业附件、重复提交、自动评分、公告、统计和管理权限测试。
- 真实异步链路：MySQL → Redis → Celery → FFmpeg → `READY/FINISHED` 通过，验收数据自动清理。
- 前端：Vite 6.4.3 生产构建通过，学习、答疑、作业、测验、统计和管理员页面均完成，所有 JavaScript 分块低于 500 kB。
- 浏览器端到端：Chromium 13/13 通过，覆盖三角色导航、受保护路由、课程发布与加入、作业提交与批改、测验自动评分、断网提示、真实 HLS 播放，以及移动端长文本、空状态和加载反馈。
- 依赖：`pip check` 正常；`npm audit` 为 0 个漏洞。
- 数据库：Flask-Migrate 检查无模型漂移。

## 已知非阻塞事项

- 当前媒体文件由 Flask 仅在开发模式提供；生产部署应交给 Nginx，并配置缓存、Range、MIME 和访问策略。
- Access/Refresh Token 当前保存在浏览器 `localStorage`。毕业设计开发阶段可接受；生产级部署建议将 Refresh Token 改为 HttpOnly、Secure、SameSite Cookie。
- 学习进度目前采用播放中定时保存与暂停时保存；离线缓存和网络恢复后的补传可在生产化阶段补充。
- 限时测验由后端严格拒绝超时提交；超时自动交卷与答案草稿自动保存可在生产化阶段补充。
- 当前浏览器自动化已覆盖主要业务闭环和学生端移动边界；教师与管理员的密集表格在手机上仍以横向滚动为主，后续可按真实使用场景改为卡片式展示。
